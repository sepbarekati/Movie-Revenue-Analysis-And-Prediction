Clustring and Vanila Neural Networks¶

Overview¶

This notebook strictly implements a clustering analysis and revenue prediction pipeline for the movies metadata dataset. It is divided into three main phases:

  1. Exploratory Data Analysis (EDA) & Data Cleaning: Initial data inspection, summary statistics generation, and missing value removal. It includes visual distribution and relationship analysis using histograms, boxplots, scatter plots, and correlation heatmaps.
  2. Clustering Analysis: Feature normalization and grouping of movies based on budget, runtime, and vote average using K-Means and Hierarchical (Agglomerative) clustering. This includes hyperparameter selection for the optimal number of clusters using inertia (the elbow method) and silhouette scores.
  3. Predictive Modeling: Train-validation-test splitting and feature scaling, followed by the construction and training of a deep fully connected neural network to predict movie revenue. The model's performance is ultimately evaluated using Mean Squared Error (MSE) and the coefficient of determination ($R^{2}$).

kmeans_silhouette = []

    # Initialize and fit K-Means

Model Architecture Summary¶

The provided summary confirms the structure of the sequential neural network built for revenue prediction:

  • Layer 1 (dense): This is the first hidden layer. The output shape of (None, 64) confirms it has 64 neurons. The None dimension indicates that the model can accept any batch size during training. This layer contains 512 trainable parameters (weights and biases), which tells us that the input data contains exactly 7 features (since $7 \times 64 \text{ weights} + 64 \text{ biases} = 512$).
  • Layer 2 (dense_1): This is the second hidden layer with 32 neurons. It takes the 64 outputs from the previous layer, resulting in 2,080 parameters ($64 \times 32 \text{ weights} + 32 \text{ biases}$).
  • Layer 3 (dense_2): This is the final output layer. It consists of a single neuron designed to output the continuous predicted revenue value. It has 33 parameters ($32 \text{ weights} + 1 \text{ bias}$).

Overall Capacity: The network has a total of 2,625 trainable parameters. Since there are no frozen layers, all 2,625 parameters will be updated by the Adam optimizer during training to minimize the Mean Squared Error.
